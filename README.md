# -E-Commerce-Logistics-Churn-Analysis-Olist-Dataset
Ao analisar os dados do e-commerce Olist, identifiquei gargalos logísticos críticos que iam além do prejuízo imediato. Dimensionando o impacto via análise de Churn e LTV, comprovei o verdadeiro custo invisível: a perda definitiva de clientes recorrentes.
